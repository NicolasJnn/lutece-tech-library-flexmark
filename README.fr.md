# Introduction

La bibliothèque Flexmark fournit des fonctionnalités pour analyser et rendre le Markdown au sein de la plateforme Lutece.

# Configuration

Pour configurer la bibliothèque Flexmark, suivez ces étapes :
Incluez la bibliothèque dans les dépendances de votre projet.Initialisez le FlexmarkService dans votre application.
Exemple d'injection dans un fichier de contexte XML :

<bean id="FlexMarkParser" class="fr.paris.lutece.plugins.flexmark.FlexMarkParser">

<property name="FlexMarkMarkdown" />

<property prefix="MD:" />

</bean>

# Usage

Pour utiliser la bibliothèque Flexmark, suivez ces étapes :
Appelez le FlexmarkService pour analyser le contenu Markdown.Spécifiez le texte Markdown à analyser.Définissez les options de rendu souhaitées pour la sortie.Récupérez le contenu HTML rendu.
Ce plugin fournit une implémentation de l'interface IRichTextContentParser, utilisée par le Lutece RichTextContentService. Le contenu à analyser doit commencer par le préfixe spécifié dans la configuration d'injection.
